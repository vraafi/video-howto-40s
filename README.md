# How-to 40 detik

Video tutorial 40 detik: 8 langkah bernomor, judul, penutup, resolusi 1280x720.

Durasi: **40 detik**.

## Isi

- `buat_video.py`

## Cara pakai

Hasil akhirnya `video.mp4` (1280x720). Untuk membuat ulang: `python buat_video.py`.

## Bukti mutu

Diperiksa otomatis dengan QC tiga lapis (kode, visual, pengguna) sebelum
diterbitkan. Vonis: **terima**.

- **kode** — lulus
- **visual** — lulus (tidak berlaku)
- **pengguna** — lulus (tidak berlaku)
- **media** — lulus

Berkas mentah hasil pemeriksaan ada di `qc.json` pada repo ini.
